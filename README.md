# VibrantLogs

**VibrantLogs** is a high-performance logging library written in C. This repository contains the **header file** and precompiled **static and dynamic libraries**. The source code is closed.

## Contents

- 'include/' - Public headers ('vibrant_logs.h')
- 'lib/static/' - Static library ('VibrantLogs.lib')
- 'lib/dynamic/' - Dynamic library ('VibrantLogs.dll' + 'VibrantLogs.lib')
